# Installation

`@sigx/store` builds on the SignalX reactive core, so it is designed to be used inside a project that already renders SignalX components with the `sigx` package.

## Install

```bash
npm install @sigx/store
```

The package is ESM-only and ships two entry points:

- `@sigx/store` — `defineStore`, `storeToSignals`, `onStoreCreated`, and their supporting types.
- `@sigx/store/persist` — the `persist` composable and its types (see [Persistence](/store/docs/persistence)).

## Dependencies

`@sigx/store` declares the reactive core as **peer dependencies**, so the app provides them — the store always uses the *same* copy of core that your components do:

- `@sigx/runtime-core` (`>=0.5.0 <0.7.0`) — factory/DI runtime (real lifetimes) and topic/subscription primitives.
- `@sigx/reactivity` (`>=0.5.0 <0.7.0`) — the signal core the state is built on.

This matters because core keeps process-wide singletons — the topic registry, the DI app-context token, `instanceof` identity. A second, separate copy of core next to the app's would silently split that shared state. Declaring them as peers guarantees one copy: whatever the app installs.

You almost certainly already have them: the `sigx` component package depends on the core, so `npm install sigx` brings `@sigx/reactivity` and `@sigx/runtime-core` along. With a package manager that auto-installs peers (npm 7+, pnpm 8+) installing `@sigx/store` next to `sigx` is enough. Otherwise add them explicitly:

```bash
npm install @sigx/store @sigx/runtime-core @sigx/reactivity
```

You use the store alongside `sigx`, which provides `component`, `render`, `signal`, and `computed`:

```bash
npm install sigx
```

## Project setup

No special Vite or build configuration is required beyond a standard SignalX + TSX/JSX setup. If your project already renders SignalX components, you can import and use `defineStore` immediately:

```ts
import { defineStore } from '@sigx/store';
```

If you are setting up a SignalX project from scratch, follow [Core → Installation](/core/docs/installation) for the JSX/TSX and Vite configuration, then add `@sigx/store` on top.

## Verify

Define a tiny store and read it in a component to confirm everything is wired up:

```tsx
import { component, render } from 'sigx';
import { defineStore } from '@sigx/store';

const usePing = defineStore('ping', ({ defineState }) => {
    const { signals } = defineState({ message: 'store is working' });
    return { ...signals };
});

const App = component(() => {
    const store = usePing();
    return () => <p>{store.message}</p>;
});

render(<App />, '#app');
```
