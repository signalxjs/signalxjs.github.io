# Installation

<p class="lede">Add `@sigx/runtime-dom` to your project.</p>

## Install the package

```bash
pnpm add @sigx/runtime-dom @sigx/runtime-core @sigx/reactivity
```

`@sigx/runtime-dom` peers on **`@sigx/reactivity`** and **`@sigx/runtime-core`** (`^1.0.0`). Most apps install `sigx` instead, which depends on all three.

## Verify

```tsx
import * as RuntimeDOM from '@sigx/runtime-dom';

console.log(Object.keys(RuntimeDOM));
```
