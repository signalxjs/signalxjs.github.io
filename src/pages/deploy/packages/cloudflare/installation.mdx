# Installation

<p class="lede">Add `@sigx/cloudflare` to your project.</p>

## Install the package

```bash
pnpm add -D @sigx/cloudflare
```

## Verify

```tsx
import * as Cloudflare from '@sigx/cloudflare';

console.log(Object.keys(Cloudflare));
```
