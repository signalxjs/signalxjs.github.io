# Installation

<p class="lede">Add `@sigx/vercel` to your project.</p>

## Install the package

```bash
pnpm add -D @sigx/vercel
```

## Verify

```tsx
import * as Vercel from '@sigx/vercel';

console.log(Object.keys(Vercel));
```
