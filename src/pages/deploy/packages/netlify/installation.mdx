# Installation

<p class="lede">Add `@sigx/netlify` to your project.</p>

## Install the package

```bash
pnpm add -D @sigx/netlify
```

## Verify

```tsx
import * as Netlify from '@sigx/netlify';

console.log(Object.keys(Netlify));
```
