## Installation

```bash
pnpm add @sigx/lynx-file-picker
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-file-picker` is a Lynx module — document picker. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
