# Installation

<p class="lede">Add `@sigx/lynx-motion` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-motion
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Motion from '@sigx/lynx-motion';

console.log(Object.keys(Motion));
```
