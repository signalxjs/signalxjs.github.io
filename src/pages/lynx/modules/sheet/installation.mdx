# Installation

<p class="lede">Add `@sigx/lynx-sheet` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-sheet
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as BottomSheet from '@sigx/lynx-sheet';

console.log(Object.keys(BottomSheet));
```
