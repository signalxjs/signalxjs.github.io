# Backdrop

<p class="lede">The dimmed overlay behind a <a href="/lynx/modules/sheet/components/bottomsheet">BottomSheet</a> — tap it to dismiss a dismissible sheet. It fades in with the sheet's reveal.</p>

## Import

```tsx
import { Backdrop } from '@sigx/lynx-sheet';
```

For a standard sheet you don't render `Backdrop` yourself — `<BottomSheet>` includes it. Reach for it directly only when composing a **custom** sheet surface from the [shared engine](/lynx/modules/sheet/api): drop a `Backdrop` behind your sheet content and wire its tap to your dismiss handler. See the [API reference](/lynx/modules/sheet/api).
