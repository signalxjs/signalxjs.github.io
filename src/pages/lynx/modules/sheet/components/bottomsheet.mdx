# BottomSheet

<p class="lede">The route-free bottom sheet — a partial-height sheet with <code>DetentSpec</code> geometry, live detents, drag and keyboard riding. The primary export of <code>@sigx/lynx-sheet</code>.</p>

## Import

```tsx
import { BottomSheet } from '@sigx/lynx-sheet';
```

`<BottomSheet>` rests at a set of **detents** (a `fraction` of the screen, a fixed `px`, or the keyboard), tracked live, in persistent or dismissible mode. See [Usage](/lynx/modules/sheet/usage) for a worked example and the [API reference](/lynx/modules/sheet/api#bottomsheet-props) for the full prop list.
