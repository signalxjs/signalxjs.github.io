# List

<p class="lede">Virtualized wrapper over the native list recycler — grid/waterfall, header/footer/empty slots, pull-to-refresh, chat mode and windowing over long histories.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/lynx-list" /> <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-list
```

## About

`@sigx/lynx-list` is a Lynx module — data-driven virtualized list. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
