# Installation

<p class="lede">Add `@sigx/lynx-maps` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-maps
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Maps from '@sigx/lynx-maps';

console.log(Object.keys(Maps));
```
