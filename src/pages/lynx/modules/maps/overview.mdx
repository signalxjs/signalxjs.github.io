# Maps

<p class="lede">Native map view with markers and regions (MKMapView / Google Maps).</p>

<p class="mod-meta-row">v0.4.9 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-maps
```

## About

`@sigx/lynx-maps` is a Lynx module — native map view. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
