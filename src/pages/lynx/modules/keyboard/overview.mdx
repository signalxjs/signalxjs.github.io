## Installation

```bash
pnpm add @sigx/lynx-keyboard
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-keyboard` is a Lynx module — soft-keyboard handling. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
