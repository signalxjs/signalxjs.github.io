# Installation

<p class="lede">Add `@sigx/lynx-dev-client` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-dev-client
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as DevClient from '@sigx/lynx-dev-client';

console.log(Object.keys(DevClient));
```
