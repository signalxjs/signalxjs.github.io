## Installation

```bash
pnpm add @sigx/lynx-datetime-picker
```

## About

`@sigx/lynx-datetime-picker` is a Lynx module — native date & time picker. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
