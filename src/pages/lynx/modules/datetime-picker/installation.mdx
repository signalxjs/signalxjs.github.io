# Installation

<p class="lede">Add `@sigx/lynx-datetime-picker` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-datetime-picker
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as DateTimePicker from '@sigx/lynx-datetime-picker';

console.log(Object.keys(DateTimePicker));
```
