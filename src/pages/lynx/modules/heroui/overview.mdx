# HeroUI

<p class="lede">HeroUI-flavored component library, stylesheet and Tailwind preset for Lynx.</p>

<p class="mod-meta-row">v0.4.9 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-heroui
```

## About

`@sigx/lynx-heroui` is a Lynx module — heroUI design system. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
