# Installation

<p class="lede">Add `@sigx/lynx-sqlite` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-sqlite
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as SQLite from '@sigx/lynx-sqlite';

console.log(Object.keys(SQLite));
```
