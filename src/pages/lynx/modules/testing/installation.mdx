# Installation

<p class="lede">Add `@sigx/lynx-testing` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-testing
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Testing from '@sigx/lynx-testing';

console.log(Object.keys(Testing));
```
