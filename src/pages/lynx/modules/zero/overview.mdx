# Zero

<p class="lede">Headless-first primitives, theme engine and Tailwind preset that custom design systems build on.</p>

<p class="mod-meta-row">v0.4.9 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-zero
```

## About

`@sigx/lynx-zero` is a Lynx module — headless design-system foundation. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
