# Installation

<p class="lede">Add `@sigx/lynx-zero` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-zero
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Zero from '@sigx/lynx-zero';

console.log(Object.keys(Zero));
```
