<p class="lede">A native fetch implementation with FormData uploads and streaming response bodies.</p>

## Installation

```bash
pnpm add @sigx/lynx-http
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-http` is a Lynx module — wHATWG fetch transport. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
