# Installation

<p class="lede">Add `@sigx/lynx-appearance` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-appearance
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Appearance from '@sigx/lynx-appearance';

console.log(Object.keys(Appearance));
```
