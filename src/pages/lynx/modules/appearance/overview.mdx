```bash
pnpm add @sigx/lynx-appearance
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-appearance` is a Lynx module — system color scheme & bars. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
