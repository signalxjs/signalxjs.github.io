## Installation

```bash
pnpm add @sigx/lynx-icons-fa-free
```

## About

`@sigx/lynx-icons-fa-free` is a Lynx module — font Awesome adapter. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
