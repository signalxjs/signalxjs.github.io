# Installation

<p class="lede">Add `@sigx/lynx-runtime` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-runtime
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Runtime from '@sigx/lynx-runtime';

console.log(Object.keys(Runtime));
```
