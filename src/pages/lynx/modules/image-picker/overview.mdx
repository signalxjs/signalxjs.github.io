## Installation

```bash
pnpm add @sigx/lynx-image-picker
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-image-picker` is a Lynx module — pick / capture images. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
