## Installation

```bash
pnpm add @sigx/lynx-icons-lucide
```

## About

`@sigx/lynx-icons-lucide` is a Lynx module — lucide adapter. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
