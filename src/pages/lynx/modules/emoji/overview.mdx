# Emoji Picker

<p class="lede">Headless categorized emoji grid with search, skin tones and recents.</p>

<p class="mod-meta-row">v0.4.9 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-emoji
```

## About

`@sigx/lynx-emoji` is a Lynx module — themable emoji picker. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
