## Installation

```bash
pnpm add @sigx/lynx-runtime-main
```

## About

`@sigx/lynx-runtime-main` is a Lynx module — main-thread (Lepus) runtime. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
