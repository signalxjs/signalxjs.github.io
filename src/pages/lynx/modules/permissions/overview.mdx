## Installation

```bash
pnpm add @sigx/lynx-permissions
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-permissions` is a Lynx module — permission helper. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
