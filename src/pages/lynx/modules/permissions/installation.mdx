# Installation

<p class="lede">Add `@sigx/lynx-permissions` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-permissions
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Permissions from '@sigx/lynx-permissions';

console.log(Object.keys(Permissions));
```
