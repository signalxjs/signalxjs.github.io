# Installation

<p class="lede">Add `@sigx/lynx-notifications` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-notifications
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Notifications from '@sigx/lynx-notifications';

console.log(Object.keys(Notifications));
```
