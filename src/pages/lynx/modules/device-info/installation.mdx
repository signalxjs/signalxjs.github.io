# Installation

<p class="lede">Add `@sigx/lynx-device-info` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-device-info
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as DeviceInfo from '@sigx/lynx-device-info';

console.log(Object.keys(DeviceInfo));
```
