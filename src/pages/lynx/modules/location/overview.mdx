## Installation

```bash
pnpm add @sigx/lynx-location
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-location` is a Lynx module — gPS coordinates. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
