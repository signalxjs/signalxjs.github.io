## Installation

```bash
pnpm add @sigx/lynx-markdown
```

## About

`@sigx/lynx-markdown` renders and edits [`@sigx/richtext`](/richtext/) trees natively. The parser, the streaming controller, the render engine and the editor core are shared with the web through `@sigx/richtext` and `@sigx/richtext-markdown` (regular dependencies); this package maps them onto Lynx views and native rich-text fields. `MarkdownView` renders a growing source without re-rendering finished blocks, and `MarkdownEditor` (from `@sigx/lynx-markdown/editor`) edits the same mdast tree block by block. It is versioned in lockstep with the rest of the Lynx module family.
