# Markdown

<p class="lede">Zero-dependency markdown parsed in JS and rendered to native views, with streaming for AI output.</p>

<p class="mod-meta-row">v0.4.9 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-markdown
```

## About

`@sigx/lynx-markdown` is a Lynx module — streaming markdown renderer. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
