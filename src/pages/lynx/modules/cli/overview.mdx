## Installation

```bash
pnpm add -D @sigx/cli @sigx/lynx-cli
```

A scaffolded Lynx app (`npm create @sigx@latest my-app -- --kind lynx`) already has both. The plugin needs Node.js 22+ and `@sigx/cli` 0.12 or later.

## About

`@sigx/lynx-cli` is a Lynx module — @sigx/cli plugin. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
