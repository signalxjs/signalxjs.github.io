# WebRTC

<p class="lede">Peer connections, audio tracks and data channels — RTCPeerConnection, RTCDataChannel, mediaDevices.getUserMedia and a native audio session.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/lynx-webrtc" /> <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-webrtc
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-webrtc` is a Lynx module — W3C-shaped WebRTC. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
