# Installation

<p class="lede">Add `@sigx/lynx-navigation` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-navigation
```

`@sigx/lynx-navigation` has five required peers. Install any you don't already have:

```bash
pnpm add @sigx/lynx @sigx/lynx-icons @sigx/lynx-motion @sigx/lynx-sheet @sigx/lynx-linking
```

`@sigx/lynx-linking` supplies URL parsing, the Android hardware back button and deep-link wiring, so it is required even if you don't route deep links.

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Navigation from '@sigx/lynx-navigation';

console.log(Object.keys(Navigation));
```
