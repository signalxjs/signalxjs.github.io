# Build Plugin

<p class="lede">Splits your source into the BG + MT bundles Lynx requires and runs the main-thread worklet transform.</p>

<p class="mod-meta-row"><strong>47k</strong> weekly <span class="mmr-dot" /> v0.4.1 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-plugin
```

## About

`@sigx/lynx-plugin` is a Lynx module — rspack / Rspeedy plugin. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
