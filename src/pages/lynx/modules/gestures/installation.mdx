# Installation

<p class="lede">Add `@sigx/lynx-gestures` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-gestures
```

## Native setup

Rebuild your development client after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Gestures from '@sigx/lynx-gestures';

console.log(Object.keys(Gestures));
```
