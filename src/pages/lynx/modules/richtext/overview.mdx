# Rich Text

<p class="lede">Attributed rich-text editing element with a span document model and formatting commands.</p>

<p class="mod-meta-row">v0.5.0 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-richtext
```

## About

`@sigx/lynx-richtext` is a Lynx module — native rich-text input. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
