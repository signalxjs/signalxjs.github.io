## Installation

```bash
pnpm add @sigx/lynx-file-system
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-file-system` is a Lynx module — sandboxed file access. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
