# Installation

<p class="lede">Add `@sigx/lynx-file-system` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-file-system
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as FileSystem from '@sigx/lynx-file-system';

console.log(Object.keys(FileSystem));
```
