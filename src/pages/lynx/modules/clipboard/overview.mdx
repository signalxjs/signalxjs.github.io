## Installation

```bash
pnpm add @sigx/lynx-clipboard
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-clipboard` is a Lynx module — system clipboard. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
