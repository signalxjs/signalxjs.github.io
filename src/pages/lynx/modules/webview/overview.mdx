# WebView

<p class="lede">Embed web content with a native WebView (WKWebView / android.webkit.WebView).</p>

<p class="mod-meta-row">v0.4.9 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-webview
```

## About

`@sigx/lynx-webview` is a Lynx module — native web view. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
