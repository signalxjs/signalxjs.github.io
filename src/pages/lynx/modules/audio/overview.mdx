# Audio

<p class="lede">Record and play audio with metering and reactive handles.</p>

<p class="mod-meta-row">v0.5.0 <span class="mmr-dot" /> iOS · Android <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/lynx-audio
sigx prebuild   # auto-links the native module
```

## About

`@sigx/lynx-audio` is a Lynx module — recording & playback. It is versioned in lockstep with the rest of the Lynx module family, so any combination of modules just works together.
