# Installation

<p class="lede">Add `@sigx/lynx-audio` to your project.</p>

## Install the package

```bash
pnpm add @sigx/lynx-audio
```

## Native setup

Native modules are autolinked by `@sigx/lynx-cli` — run a prebuild after installing:

```bash
sigx prebuild
```

## Verify

```tsx
import * as Audio from '@sigx/lynx-audio';

console.log(Object.keys(Audio));
```
