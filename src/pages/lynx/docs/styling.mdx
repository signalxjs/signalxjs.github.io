# Styling & layout

<p class="lede">Every element lays out with flexbox; styles are typed objects (or DaisyUI classes via @sigx/lynx-daisyui).</p>

## Style objects

```tsx
<View style={{ flexDirection: 'row', gap: 12, padding: 16 }}>
    <Text style={{ fontSize: 16, color: '#e7e9f1' }}>Styled natively</Text>
</View>
```

## Flexbox by default

Lynx's layout engine speaks flexbox natively — `flexDirection`, `gap`, `alignItems`, `justifyContent` behave like the web.
