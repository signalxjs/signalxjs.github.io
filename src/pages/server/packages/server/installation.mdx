# Installation

<p class="lede">Add `@sigx/server` to your project.</p>

## Install the package

```bash
pnpm add @sigx/server
```

## Verify

```tsx
import * as ServerFunctions from '@sigx/server';

console.log(Object.keys(ServerFunctions));
```
