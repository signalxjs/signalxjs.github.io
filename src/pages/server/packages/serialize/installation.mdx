# Installation

<p class="lede">Add `@sigx/serialize` to your project.</p>

## Install the package

```bash
pnpm add @sigx/serialize
```

## Verify

```tsx
import * as Serialize from '@sigx/serialize';

console.log(Object.keys(Serialize));
```
