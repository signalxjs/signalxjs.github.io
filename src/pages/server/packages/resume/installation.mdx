# Installation

<p class="lede">Add `@sigx/resume` to your project.</p>

## Install the package

```bash
pnpm add @sigx/resume
```

## Verify

```tsx
import * as Resume from '@sigx/resume';

console.log(Object.keys(Resume));
```
