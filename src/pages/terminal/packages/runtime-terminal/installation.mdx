# Installation

<p class="lede">Add `@sigx/runtime-terminal` to your project.</p>

## Install the package

```bash
pnpm add @sigx/runtime-terminal
```

## Verify

```tsx
import * as RuntimeTerminal from '@sigx/runtime-terminal';

console.log(Object.keys(RuntimeTerminal));
```
