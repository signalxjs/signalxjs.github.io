# Installation

<p class="lede">Add `@sigx/terminal-ui` to your project.</p>

## Install the package

```bash
pnpm add @sigx/terminal-ui
```

## Verify

```tsx
import * as TerminalUI from '@sigx/terminal-ui';

console.log(Object.keys(TerminalUI));
```
