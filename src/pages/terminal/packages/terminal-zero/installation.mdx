# Installation

<p class="lede">Add `@sigx/terminal-zero` to your project.</p>

## Install the package

```bash
pnpm add @sigx/terminal-zero
```

## Verify

```tsx
import * as TerminalZero from '@sigx/terminal-zero';

console.log(Object.keys(TerminalZero));
```
