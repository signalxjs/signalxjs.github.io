# Kubernetes

<p class="lede">Membership with no extra store — one Lease per host, renewed as a heartbeat and watched by label selector, so the cluster you are already running is the membership provider. Pairs with a Redis or Postgres directory.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/actors-k8s" /> <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/actors-k8s
```

## About

`@sigx/actors-k8s` is a Actors package — host liveness on coordination.k8s.io Leases. It is versioned in lockstep with the rest of the actors repo, so any combination of backends, transports and tools just works together.
