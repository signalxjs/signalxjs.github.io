# OpenTelemetry

<p class="lede">Scrape-ready Prometheus text on an OTel-free entry, plus spans that join across hosts through the propagated traceparent. Labels are type and method — never actor keys.</p>

## Installation

```bash
pnpm add @sigx/actors-otel
```

## About

`@sigx/actors-otel` is a Actors package — prometheus exposition & OTel traces. It is versioned in lockstep with the rest of the actors repo, so any combination of backends, transports and tools just works together.
