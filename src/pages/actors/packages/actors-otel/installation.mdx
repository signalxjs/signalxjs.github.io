# Installation

<p class="lede">Add `@sigx/actors-otel` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-otel
```

## Verify

```tsx
import * as OpenTelemetry from '@sigx/actors-otel';

console.log(Object.keys(OpenTelemetry));
```
