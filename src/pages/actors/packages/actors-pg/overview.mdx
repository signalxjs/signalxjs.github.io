# Postgres

<p class="lede">The whole cluster on the database you already run — jsonb storage with etag compare-and-set, database-clock membership, the directory, and durable reminders claimed with SKIP LOCKED. Ships its DDL; never issues it for you.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/actors-pg" /> <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/actors-pg
```

## About

`@sigx/actors-pg` is a Actors package — membership, directory, storage & reminders on Postgres. It is versioned in lockstep with the rest of the actors repo, so any combination of backends, transports and tools just works together.
