# Installation

<p class="lede">Add `@sigx/actors-pg` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-pg
```

## Verify

```tsx
import * as Postgres from '@sigx/actors-pg';

console.log(Object.keys(Postgres));
```
