# Installation

<p class="lede">Add `@sigx/actors-ws` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-ws
```

## Verify

```tsx
import * as WebSocket from '@sigx/actors-ws';

console.log(Object.keys(WebSocket));
```
