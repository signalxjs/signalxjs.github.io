# WebSocket

<p class="lede">The same frame codec as TCP, over one port your proxy already forwards. Attaches to your existing HTTP server as an upgrade handler — the one thing a contributed route cannot express.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/actors-ws" /> <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/actors-ws
```

## About

`@sigx/actors-ws` is a Actors package — host-to-host frames over the HTTP port. It is versioned in lockstep with the rest of the actors repo, so any combination of backends, transports and tools just works together.
