# Installation

<p class="lede">Add `@sigx/actors-cloudflare` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-cloudflare
```

## Verify

```tsx
import * as Cloudflare from '@sigx/actors-cloudflare';

console.log(Object.keys(Cloudflare));
```
