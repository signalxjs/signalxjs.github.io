# Redis

<p class="lede">The usual first step out of one process — host membership, the distributed actor directory and etag-CAS actor storage, all on one ioredis client. Requires Redis 7 for SET NX GET.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/actors-redis" /> <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/actors-redis
```

## About

`@sigx/actors-redis` is a Actors package — membership, directory & storage on Redis. It is versioned in lockstep with the rest of the actors repo, so any combination of backends, transports and tools just works together.
