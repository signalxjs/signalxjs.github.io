# Installation

<p class="lede">Add `@sigx/actors-redis` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-redis
```

## Verify

```tsx
import * as Redis from '@sigx/actors-redis';

console.log(Object.keys(Redis));
```
