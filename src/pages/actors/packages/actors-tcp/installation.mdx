# Installation

<p class="lede">Add `@sigx/actors-tcp` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-tcp
```

## Verify

```tsx
import * as TCP from '@sigx/actors-tcp';

console.log(Object.keys(TCP));
```
