# Installation

<p class="lede">Add `@sigx/actors-cli` to your project.</p>

## Install the package

```bash
pnpm add @sigx/actors-cli
```

## Verify

```tsx
import * as CLI from '@sigx/actors-cli';

console.log(Object.keys(CLI));
```
