# CLI

<p class="lede">A @sigx/cli plugin: sigx actors top, stats and health. Reads a running host over its ops endpoint, or loads your app module in-process for zero-config local use.</p>

<p class="mod-meta-row"><PkgVersion npm="@sigx/actors-cli" /> <span class="mmr-dot" /> MIT</p>

## Installation

```bash
pnpm add @sigx/actors-cli
```

## About

`@sigx/actors-cli` is a Actors package — sigx actors — a terminal dashboard. It is versioned in lockstep with the rest of the actors repo, so any combination of backends, transports and tools just works together.
